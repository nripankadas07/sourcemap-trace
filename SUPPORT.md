# Support, contribution and security

Report reproducible bugs in this repository’s Issues with tool/Python version, operating system, a minimal synthetic input, expected behavior and exact error. Do not upload credentials, private notebooks, source maps, customer data or Git LFS assets. No response-time guarantee.

Contributions should keep the bounded contract, add a meaningful failure regression, preserve read-only behavior where specified, update examples, and pass tests, package installation and supported Python CI. Do not weaken checks to make a failure disappear.

For suspected vulnerabilities use GitHub private vulnerability reporting if enabled; otherwise contact the maintainer through their public profile without including exploitable private data in a public issue. This MVP is not a security sandbox. Use stable local files you control; no protection against concurrent filesystem replacement. Treat output path labels and report contents as data.
